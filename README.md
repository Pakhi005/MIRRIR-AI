# AI Mock Interview

Welcome to the AI Mock Interview project! 

## Deployment
The application is deployed and can be accessed at: [mirror-ai.sbs](https://mirror-ai.sbs)

## Structure
- `frontend/`: Contains the frontend web application code.
- `backend-node/`: Node.js backend.
- `backend-python/`: Python backend, typically used for AI/ML inference or heavy processing.
- `docker-compose.yml`: For containerized deployment.
- `setup_nginx.sh`: Nginx setup script.
